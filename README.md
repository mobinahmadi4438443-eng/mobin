# Fragment Shop Bot

ربات فروشگاهی تلگرام برای فروش **استارز** و **پرمیوم** — تک‌فایل (`index.php`)، دیتابیس **SQLite**، آماده‌ی دیپلوی روی **Railway**.

تمام تنظیمات (جوین اجباری، درگاه، کارت، آدرس ولت‌ها، نرخ ارز، قیمت استارز، ادمین‌ها) **از داخل خود ربات** و از دکمه‌های پنل ادمین انجام می‌شود؛ فقط دو متغیر اجباری لازم است.

## امکانات

- منوی اینلاین: حساب کاربری، سرویس‌ها، راهنما و قوانین، افزایش موجودی، پشتیبانی
- دسته‌بندی سرویس (اصلی/فرعی)، فروش استارز و پرمیوم، کسر اتمیک موجودی
- تایید/رد سفارش توسط ادمین (رد = بازگشت خودکار مبلغ)
- شارژ حساب: درگاه IDPay، ترون (TRX)، گرام (TON)، کارت به کارت
- قیمت خودکار استارز از `fragment.com/stars/buy` (بروزرسانی هر ۵ دقیقه + اعلام قیمت جدید به ادمین‌ها)
- نرخ ارز: دستی، خودکار (نوبیتکس) یا API دلخواه برای ترون و گرام جداگانه
- جوین اجباری (تا ۸ کانال/گروه، عمومی و خصوصی)
- انتقال موجودی بین کاربران، تاریخ شمسی
- ست‌شدن خودکار وبهوک (با secret token) و تشخیص خودکار آدرس سرور

## دکمه‌های پنل ادمین (`/admin`)

| دکمه | کاربرد |
|---|---|
| 👑 مدیریت ادمین‌ها | افزودن/حذف ادمین با آیدی عددی، فوروارد پیام یا مخاطب (فقط ادمین اصلی) |
| 📢 قفل جوین اجباری | افزودن کانال با @یوزرنیم، لینک، آیدی عددی یا فوروارد پست؛ تست عضویت، روشن/خاموش، حذف |
| 🌐 درگاه پرداخت ریالی | کلید API ایدی‌پی، حالت آزمایشی، حداقل/حداکثر مبلغ، تست اتصال، آدرس callback |
| 💳 تنظیم کارت به کارت | شماره کارت (با اعتبارسنجی) ← نام و نام خانوادگی ← ساخت متن کارت |
| 🪙 آدرس ترون / 💎 آدرس گرام (TON) | ثبت و اعتبارسنجی آدرس، روشن/خاموش، حذف |
| 💱 نرخ ارز | نرخ دستی، خودکار (نوبیتکس) یا API دلخواه برای هر ارز |
| ⭐ قیمت استارز | قیمت‌گذاری خودکار از Fragment، درصد سود، گرد کردن، انتخاب سرویس‌های خودکار |

## استقرار روی Railway

1. پروژه را روی GitHub بگذارید و در Railway «Deploy from GitHub repo» بزنید (فایل `Dockerfile` خودکار شناسایی می‌شود).
2. در تب **Variables** این دو متغیر را بسازید: `BOT_TOKEN` و `ADMIN_ID`.
3. در **Settings → Networking** روی **Generate Domain** بزنید (برای وبهوک و درگاه پرداخت لازم است).
4. **مهم:** در **Settings → Volumes** یک Volume با Mount Path برابر `/data` بسازید، وگرنه با هر دیپلوی دیتابیس پاک می‌شود.
5. Redeploy کنید. وبهوک و دیتابیس خودکار ساخته می‌شوند. سپس در تلگرام `/start` و `/admin` را بزنید.

## متغیرها

| متغیر | اجباری | توضیح |
|---|---|---|
| `BOT_TOKEN` | بله | توکن ربات از BotFather |
| `ADMIN_ID` | بله | آیدی عددی ادمین اصلی (چند ادمین: با کاما جدا کنید) |
| `BOT_USERNAME` | خیر | یوزرنیم ربات بدون @ (خودکار با getMe پیدا می‌شود) |
| `TONCENTER_API_KEY` | خیر | کلید Toncenter (برای جلوگیری از محدودیت نرخ) |
| `TRONGRID_API_KEY` | خیر | کلید TronGrid |
| `WEB_URL` | خیر | فقط برای دامنه سفارشی؛ پیش‌فرض از `RAILWAY_PUBLIC_DOMAIN` خوانده می‌شود |
| `SQLITE_PATH` | خیر | مسیر دیتابیس؛ پیش‌فرض `RAILWAY_VOLUME_MOUNT_PATH/bot.db` یا `/data/bot.db` |

متغیرهای قدیمی `CHANNEL_*`, `IDPAY_*`, `CARD_NUMBER`, `TON_WALLET`, `TRON_WALLET`, `TON_RATE_TOMAN`, `TRX_RATE_TOMAN` دیگر استفاده نمی‌شوند و باید از پنل ربات تنظیم شوند.

## ساختار دیتابیس

جدول‌های نسخه‌ی قبلی (`users`, `setting`, `ProductsA`, `ProductsF`, `Orders`, `texts`, `code`, `trons_pay`, `tron_pays`, `ton_pays`, `admin`) حفظ شده‌اند. دو جدول جدید `kv` (تنظیمات کلید/مقدار) و `joincache` (کش عضویت) به صورت خودکار اضافه می‌شوند.

## آدرس‌ها

| مسیر | کاربرد |
|---|---|
| `/webhook` | وبهوک تلگرام |
| `/pay` , `/pay/back` | ساخت و تایید پرداخت IDPay |
| `/health` | چک سلامت Railway |
| `/setwebhook?token=BOT_TOKEN` | ست دستی وبهوک (فقط اگر دامنه خودکار شناسایی نشد) |

## اجرای محلی

```bash
BOT_TOKEN=... ADMIN_ID=... php -S 127.0.0.1:8080 index.php
```
